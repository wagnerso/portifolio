# Portfólio - Wagner Santos de Oliveira

Meu portfólio pessoal com projetos de desenvolvimento web.

## Projetos

### Conta Clara
Aplicação web estática para educação financeira pessoal.

- **Funcionalidades:** Calculadora de salário, registro de gastos, metas SMART, simulador de aposentadoria
- **Tecnologias:** HTML, CSS, JavaScript puro
- **Status:** Em desenvolvimento

### Kognis
Sistema de formulários de triagem psicológica para adultos.

- **Formulários:** SRS-2, BDEFS, BSI
- **Funcionalidades:** Auto-avanço, teclado, persistência de dados, cálculo automático
- **Tecnologias:** HTML, CSS, JavaScript puro
- **Status:** Funcional

## Como executar

1. Clone o repositório:
```bash
git clone git@github.com:wagnerso/portifolio.git
```

2. Abra o `index.html` no navegador
